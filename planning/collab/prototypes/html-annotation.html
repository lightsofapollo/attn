On the Quiet Power of Margins

Every document carries a second document beside it — the conversation in the margin. We rebuilt it for the web.

Field Notes · Collaboration team · 6 min read

The margin is the oldest collaborative surface we have. Medieval scribes argued with their sources in the gutter; readers for centuries have pressed their disagreements into the white space beside a paragraph. The text stays fixed and authoritative while the margin stays loose, personal, and alive. A good annotation system is really just a way to keep those two registers — the work and the talk about the work — visible at the same time.

When the surface being annotated is rendered HTML rather than plain prose, the problem gets interesting. HTML has structure: a paragraph is a node, an image is a node, a table is a node. We can anchor a comment to a run of text or to a whole element, and those are genuinely different gestures with different meanings.

A comment on a sentence is an argument. A comment on a figure is a verdict.

Two ways to point

Text anchoring uses a quote selector: the exact words, plus a little context on either side so the anchor survives small edits. Element anchoring uses a CSS selector that resolves to a single node. Both serialize into the same envelope, so a thread doesn't care which kind of anchor it hangs from.

// one envelope, two anchor flavors
type Anchor =
  | { kind: "text"; quote; prefix; suffix }
  | { kind: "element"; cssSelector; tagName };

The highlight itself is drawn with the CSS Custom Highlight API — no wrapper spans injected into the document, so the page you are annotating is never mutated. That matters when the HTML came from somewhere you don't fully trust.

What survives an edit

The hard part isn't drawing the highlight — it's keeping it attached when the document changes underneath it. Each anchor carries several fallback layers, tried in order of confidence:

LayerMatches onConfidence
Exact quoteverbatim text + context0.90
Block fingerprintstructural hash + offset0.85
Fuzzy quoteedit-distance match0.50–0.75
Line proximitynearest original line0.35

When every layer fails, the thread doesn't vanish — it drops into an orphan tray at the top of the rail, waiting for a human to re-anchor it. Nothing is ever silently lost. That single rule, more than any clever matching, is what makes people trust the margin enough to actually use it.
