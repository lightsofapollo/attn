# Generated Icon Packs

DO NOT EDIT BY HAND. Regenerate with:

```
npm run refresh:icons
```

This directory is committed so that `npm ci` and the build need nothing but
the lockfile and the npm registry. Three of the packs are not published to npm
and were previously `github:` dependencies, which made every install depend on
resolving an unrelated project's floating dependencies at install time.

Included runtime packs:
- `material`
- `eyecons`
- `catppuccin`
- `vscode-icons`
- `seti`

Default pack:
- `eyecons`

## Provenance

From the npm registry, pinned by web/package-lock.json:
- `material-icon-theme@5.31.0` (MIT)
- `seti-file-icons` (MIT)

(pins live in web/scripts/icon-pack-pins.mjs):
