What the agent gets
Stable feedback and thread IDs; the actual local file path when available; the quoted passage, heading or HTML selector; your note and replies; snapshot/hash and current anchor confidence. It verifies the passage before editing.

        
How it stays simple
Both commands read the existing local attn store. Personal marks live in attn’s own metadata. Readable text is the default; --json gives a structured snapshot. Watch emits one JSON record per line through the existing local daemon.

        
Who runs the agent
Your agent host keeps the watch process running and consumes its output. The host chooses the provider/model and when to act. Delivery can be prompt; interrupting an active model call depends on the host. Responses stay in your agent dialogue.

        
What v1 can reach
Existing room-backed comments on this machine. Browser-only marks stay in that browser and support direct copy; they need local import and native marking to reach this CLI. Unshared local commenting and cross-device mark sync are separate work.

      

      
Implementation contract & boundaries
Project scope. Run either command from the source project, or pass a file/project path. Scope resolves from local workspace bindings. No implicit scan of unrelated projects. Snapshot reads work from persisted data with the daemon stopped and report local freshness; watch requires the daemon.
Continuous stream. Snapshot first, then upsert and remove records. Subscribe without a startup gap. Human follow-ups advance a durable feedback revision; agent replies and file reloads only update context/source revisions. Unmarking or resolving removes queued work; it cannot undo an edit already made.
Recoverable delivery. A lost stream position or buffer overflow emits reset and a fresh snapshot. Daemon loss exits with an error; the host restarts the command. Deduplicate by scoped feedback ID and revision. No saved cursor file or acknowledgement command is needed. Ctrl-C stops watching.
Original files. attn stays the source of notes; the filesystem stays the source of documents. Agents use their existing permissions and recheck stale/ambiguous anchors. attn preserves dirty editor buffers when external edits arrive. Reading, copying and watching leave threads open.
Implementation scope. No additional exported Markdown inbox, public HTTP API, required MCP adapter, model runner, automatic agent replies or new review/acceptance step. Commands and output are proposed here; this artifact does not implement them.
