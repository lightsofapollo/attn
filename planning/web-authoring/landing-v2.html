01 / THE MODEL

A document first. A room only when you share.

The existing site starts with collaboration. This version starts one beat earlier: the private document. Sharing does not turn it into a cloud file—it publishes an encrypted revision around which review can happen.

01

Create locally

One click creates a workspace with untitled.md. Add more Markdown, images, or project assets; larger encrypted bodies can use OPFS.

02

Share deliberately

Share creates a bounded review room and a secret-bearing link. Attn’s services store ciphertext, never a readable cloud copy.

03

Review anywhere

Browser and native clients share the same comments, suggestions, live edits, encrypted mailbox, and peer-to-peer path.

The moment local becomes shared

“A room exists only after you press Share.”

The current landing already explains E2EE well. The revision is to put that guarantee at the transition point—after someone understands where their source lives.

02 / TWO SURFACES

Use the lightest tool for the work.

The browser is the fastest way to begin or join. Native attn remains the best tool for local folders, repository-scale navigation, media, and a window that lives beside the work.

Browser · no install

Your private desk

Create, import, edit, back up, and share multi-file Markdown workspaces without signing up. Images and other assets retain their relative paths and export as normal files.

  • → New document in one click
  • → iPhone and iPad Safari
  • → Installable for offline launch
Native · local folders

The whole workspace

Open repositories and folders from the terminal. Keep live reload, tabs, Mermaid, math, media, search, and the same encrypted review protocol.

  • → One small Rust binary
  • → Existing files stay where they are
  • → Browser invites open here too

Native attn is still first-class

Your files. A real window.

The current landing’s feature tour remains valuable, but moves below the browser story. Install native attn when you want whole folders, terminal launch, live reload, and a dedicated review workspace.
