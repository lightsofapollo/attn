Q3 Launch Plan

Agent draft · shared for review 2 hours ago · 2 open threads

This plan covers the public launch of the mesh CLI: the producer loop demo, the pricing page, and the burst-training benchmark we publish alongside it. The goal is a launch that a single founder can run end-to-end without touching a cloud console.

The core claim we are making is that training bursts should move to wherever compute is cheapest that hour, and the demo has to make that visible in under ninety seconds. Everything else in this document is subordinate to that moment. The benchmark provesdemonstrates the arbitrage on a real fine-tune, not a synthetic batch job.

Timeline

  • Week 1: freeze the CLI surface; record the producer-loop demo against owned metal.
  • Week 2: benchmark run across owned + rented capacity; draft the launch post.
  • Week 3: launch. Post, demo, benchmark, and pricing go live together.
  • Freeze gpu rent flags for the demo path
  • Record 90-second producer-loop capture
  • Publish CAS artifact manifest for the benchmark run
  • Draft launch post and route it through attn for review

Rollout gates

Each gate is a command, not a meeting. The launch holds until all three exit zero:

BASH# gate 1: the demo runs clean from a fresh install
gpu demo producer-loop --fresh --timeout 90s

# gate 2: burst benchmark reproduces within 5%
gpu bench burst --manifest cas://launch-q3 --tolerance 0.05
